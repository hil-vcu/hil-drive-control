## 결정 근거

### 1. 비트레이트 500 kbps
자동차 파워트레인 표준 속도. 1 Mbps는 배선 품질에 민감해 브레드보드 환경에서 에러가 난다.
샘플포인트 87.5%는 CiA 권장값.

### 2. ID 배치
CAN 중재에서 ID가 작을수록 우선순위가 높다. 안전 관련 신호에 가장 낮은 ID를 배정하여
버스 부하가 높은 상황에서도 제동 명령이 우선 전송되게 한다.

### 4. 단위 규약
단위 혼용은 부호·스케일 버그의 주요 원인이다. 내부 연산을 SI로 통일하고
변환은 표시 계층에서만 수행한다.

### 7. 하드웨어 비의존 설계
동일한 제어 로직 소스를 PC(SIL)와 STM32(HIL) 양쪽에서 컴파일해야
"SIL과 HIL이 같은 로직"이라는 주장이 성립한다. 또한 순수 함수여야 단위테스트가 가능하다.
