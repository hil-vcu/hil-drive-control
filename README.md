# 저비용 HIL 환경 기반 차량 구동제어 시스템 개발 및 검증

실물 STM32 제어기와 가상 차량 플랜트를 CAN으로 연결한 저비용 HIL 환경을 구축하고,
그 위에서 구동 제어기(VCU)를 개발·검증한다.

## 구조
- `control/`   하드웨어 비의존 제어·추정 로직 (SIL·펌웨어가 공유)
- `plant/`     차량 종방향 동역학 모델
- `input/`     페달 입력 노드
- `firmware/`  STM32 펌웨어
- `hmi/`       모니터링 화면
- `tests/`     GoogleTest 단위테스트
- `scenarios/` 시험 시나리오 (YAML)
- `dbc/`       CAN 메시지 정의
- `tools/`     시나리오 러너, 리포트 생성
- `docs/`      설계 결정, 요구사항, 작업로그

## 노드 구성
| 노드 | 하드웨어 | 역할 |
|---|---|---|
| 운전 입력 | 라즈베리파이 5 + USB-CAN | 페달·버튼 입력을 CAN으로 인코딩 |
| 제어기 (검증 대상) | STM32 Nucleo-F446RE + SN65HVD230 | FreeRTOS, 1 kHz 제어 루프 |
| 검증 | 라즈베리파이 5 (별도 프로세스) | 플랜트 시뮬레이션, 시나리오 자동 시험 |

논리 노드 3개 / 물리 장치 2개 구성.
